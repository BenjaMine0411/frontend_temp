# VTON 試衣間：前端設計規格

`index.html` 是可以直接打開的完整原型（純 HTML／CSS／JS，沒有框架、不用建置）。視窗寬度 900px 以下是手機版，以上是電腦版。

## 放置方式

```
web_frontend/
├── index.html               ← 網頁
├── library.js               ← 資料邏輯（選項、變灰規則、找影片）
├── DESIGN_SPEC.md           ← 本文件
├── make_sample_library.py   ← 產生示範資料庫的腳本
├── sample_assets/           ← 示範用的 5 支影片、4 張縮圖、catalog.json
└── video_library/           ← 影片資料庫（網頁讀這裡；由腳本產生示範版，不進版控）
```

### 怎麼打開看

```bash
cd web_frontend
python make_sample_library.py     # 產生示範資料庫 video_library/（只需做一次）
python -m http.server 8000        # 然後用瀏覽器開 http://localhost:8000/
```

影片要透過網址（http）讀取，直接用檔案方式（file://）開啟，部分瀏覽器會讀不到影片。

## 資料串接（已完成）

頁面的資料與選項規則都在 `library.js`，`index.html` 只負責呈現。

```
video_library/             ← 影片資料庫
├── manifest.json          有哪些影片（由 video_generation/build_index.py 產生）
├── catalog.json           顯示名稱、身高體重區間
├── thumbnails/            衣服縮圖，檔名 <衣服名稱>.png
└── <下身>+<上身>/<gender>/h<身高>_w<體重>/<動作>.mp4（旁邊各有一個 .json 說明檔）
```

示範資料庫是 `make_sample_library.py` 用和真正流程完全相同的格式產生的（同樣的資料夾命名、說明檔、`build_index.py` 產生的索引），只是影片內容是 5 支示範影片輪流充當。**真正的影片產生後，用真正的資料庫資料夾取代 `video_library/` 的內容即可，網頁不用改**（資料庫根目錄要有 `manifest.json`、`catalog.json` 與 `thumbnails/`）。預設是**完整覆蓋**（每個選項都有影片，沒有任何選項會變灰）。想試「沒有影片的選項會變灰」的效果，用 `python make_sample_library.py --sparse` 產生覆蓋不完整的版本。

- `index.html` 裡只有一個設定：`const LIB = 'video_library/'`，指向資料庫資料夾。
- 選項（性別、身高區間、體重區間、衣服、動作）全部由 `manifest.json` 與 `catalog.json` 決定，頁面不寫死任何選項。數量增減不用改程式。
- 身高、體重區間在 `catalog.json` 定義，每個區間有一個 `value`（中間值，例如 150–160 對應 155）。影片就是用這個數值產生的。

### 哪些選項會變灰（不能點）

一個選項在「它所依賴的、已經選好的欄位」之下沒有任何影片時變灰，且不能點：

| 欄位 | 受什麼限制 |
|---|---|
| 性別 | 不受限（只要有該性別的影片就能選）；切換性別時，不合的身高體重會自動清掉 |
| 身高 | 受性別限制 |
| 體重 | 受性別與身高限制 |
| 上身 / 下身 | 受身形與另一件衣服限制（**不受動作限制**）；再點一次已選的衣服可取消選擇 |
| 動作 | 受以上全部限制；換衣服時，如果目前的動作這組沒有，會自動換成第一個有影片的動作 |

所以使用者不會選到沒有影片的組合，也不會被某個選擇卡住。

### 如果要修改視覺

可以自由調整 HTML 與 CSS。請保留：`<script src="library.js">` 與底下 `<script>` 裡呼叫 `lib.*` 的資料邏輯（`renderBodyPage`、`renderTryPage`、`loadVideo` 等）。`library.js` 提供的介面見該檔案開頭的說明。

## 頁面流程

1. **身形頁**：性別（兩個大按鈕）、身高（下拉選單）、體重（下拉選單）。三項都選了，「開始試穿」才會亮起。
2. **試穿頁**：
   - 手機：上方是身形標籤（點一下回第一頁），中間是影片，下方依序是動作、上身列、下身列（左右滑動）。
   - 電腦：頂列顯示目前身形和「修改」按鈕；左半邊是影片，右半邊是動作、上身、下身的卡片格（選項多時右側上下捲動）。
   - 換任何一件衣服或動作，影片都在原地切換，不換頁。

## 影片區狀態

| 狀態 | 什麼時候 | 畫面 |
|---|---|---|
| 空狀態 | 上身或下身還沒選 | 衣架圖示＋「選一件上身和一件下身」／「再選一件下身」／「再選一件上身」 |
| 載入中 | 換了選擇、影片還沒載入 | 白底藍色轉圈＋「換裝中…」 |
| 播放中 | 影片載入完成 | 自動播放、循環、靜音；左下（電腦版置中）顯示目前搭配與動作 |
| 錯誤 | 沒有影片或載入失敗 | 「這段影片暫時無法播放」＋「重新載入」按鈕 |

## 配色

| 名稱 | 色碼 | 用途 |
|---|---|---|
| 底色 | `#FFFFFF` | 頁面與影片區，和影片白背景接在一起 |
| 淺灰面 | `#F3F3F1` | 衣服縮圖底、身形標籤、電腦版首頁左側 |
| 外框線 | `#DADAD5` | 未選中的按鈕和選單 |
| 分隔線 | `#EDEDEA` | 區塊之間 |
| 墨黑 | `#141416` | 文字、選中狀態（黑底白字或黑框） |
| 次要文字 | `#63636A` | 小標、提示 |
| 停用 | `#A3A3A8` | 不能點的動作 |
| 鈷藍 | `#3B4CCA` | 只用在播放中小圓點、載入轉圈、鍵盤焦點框 |

## 字體

Noto Sans TC（Google Fonts，400／500／700）。只用一套字，靠粗細和字距分層次。

| 用途 | 手機 | 電腦 |
|---|---|---|
| 大標 | 30px／700 | 40px（首頁左側主標 48–72px） |
| 選項文字 | 15–18px／500 | 21–24px／500 |
| 小標 | 13px／700，字距 0.12em，灰色 | 18px |
| 品牌字「VTON 試衣間」 | 13px／700，字距 0.28em | 16px |

## 元件尺寸

| 元件 | 手機 | 電腦 |
|---|---|---|
| 性別按鈕 | 高 64、圓角 16 | 高 76、圓角 20 |
| 下拉選單 | 高 58、圓角 16 | 高 76、圓角 20 |
| 主要按鈕 | 高 58、全圓角 | 高 72、最小寬 320 |
| 動作按鈕 | 高 40、全圓角 | 高 60、全圓角 |
| 衣服卡 | 76×76、圓角 14 | 自動填滿格子（最小 120）、圓角 18 |

所有可點的東西都至少 40px 高，選中狀態不只靠顏色（同時有黑底或黑框），也有 `aria-pressed` 給螢幕閱讀器。
