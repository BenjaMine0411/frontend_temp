# 新前端：預先產生影片的虛擬試穿展示

這個資料夾包含新版展示的全部內容，分成兩個部分：

```
new_frontend/
  video_generation/    產生影片的工具（給負責跑影片的組員）
  web_frontend/        展示網頁（設計說明與開發素材）
```

## 整體做法

舊版的網頁是使用者輸入後現場模擬、算圖，一支影片要十幾分鐘，不適合展示。新版改成：

1. 先把「衣服 × 性別 × 身高區間 × 體重區間 × 動作」的所有組合，在各自的電腦上批次產生成影片。
2. 把大家產生的影片合併成同一個影片資料庫。
3. 網頁只負責讓使用者選擇身形、衣服與動作，然後播放對應的影片。網頁是純靜態的，不需要 GPU，也不需要連回任何人的電腦，因此可以放在免費的靜態網站主機上，用 QR code 讓大家掃描使用。

```
 video_generation/                              web_frontend/
 ┌──────────────────────────┐                  ┌──────────────────────┐
 │ 每位組員依分工填工作單    │                  │ 兩頁的展示網頁         │
 │ 批次產生影片              │   合併影片資料庫  │ 選身形 → 選衣服動作    │
 │ (check_setup 先自我檢查)  │ ───────────────▶ │ → 播放對應影片         │
 └──────────────────────────┘   + 索引檔        └──────────────────────┘
```

## 從哪裡開始

- **要跑影片的人**：看 `video_generation/README.md`，照步驟操作。
- **要做網頁介面的人**：看 `web_frontend/DESIGN_BRIEF.md`（設計需求）與 `web_frontend/DESIGN_SPEC.md`（設計成果與資料串接）。先在 `web_frontend/` 執行 `python make_sample_library.py` 產生示範資料庫，再執行 `python -m http.server 8000`，用瀏覽器開 `http://localhost:8000/` 就能操作。
